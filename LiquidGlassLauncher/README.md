# Liquid Glass Launcher (Android 9+)

Launcher in stile iOS 26: vetro liquido, icone squircle, schermata di blocco con orologio che si allunga e si restringe.

## Ottenere l'APK con GitHub
1. Crea un repository su GitHub e carica tutto il contenuto di questa cartella (compresa `.github`).
2. Vai su **Actions → Build APK** (parte da solo al push, oppure **Run workflow**).
3. A fine build scarichi l'APK da **Releases** (`LiquidGlassLauncher.apk`) oppure da **Artifacts**.
4. Installalo sul telefono (consenti "origini sconosciute") e premi Home → scegli *Liquid Glass*.

## Uso
- Lock screen: trascina l'orario in verticale per allungarlo/restringerlo; tieni premuto per personalizzare (peso, altezza, carattere, colore, stile); scorri verso l'alto per sbloccare.
- Tieni premuto sulla home: cambia sfondo, blocca schermo.
- Tieni premuto su un'icona: info / disinstalla.
